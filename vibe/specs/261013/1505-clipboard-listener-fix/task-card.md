# 剪贴板采集与长驻监听修复

## 范围与业务保护

1. 用户授权修复保护期漏采及长驻监听输出上限，并保留采集频率、防循环保护；本轮仅提交这两项及原生监听的必要依赖。
2. 原生序号检测和回退轮询仍为 300ms；恢复保护仍为 500ms、最多恢复次数仍为 3；自写回身份、别名粘贴、行处理抑制及原有数据语义保留。
3. 原生保护期事件合并为保护结束后的当前值读取；读取时保留原写回身份。如果补采开启新保护期，旧定时器不清除新身份。回退轮询不推进被保护期拒绝的内容。
4. 长驻进程改用流式 stdout/stderr；ASAR 内的随包二进制复制到私有临时目录后启动，退出或同步/异步启动失败后清理。开发目录及原有 Windows/Linux、外置 macOS 程序入口保留。
5. 不变更数据库结构、迁移、SQLite/JSON facade 或业务数据；更早的 GIF、企业微信采集和快捷键改动不在此次提交中。
6. 原有检测频率只能采样当前内容；保护期内多次事件合并后，不能恢复已经被后续复制覆盖的中间内容。
