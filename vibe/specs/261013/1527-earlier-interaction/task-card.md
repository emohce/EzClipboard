# 早期交互改动提交核验

## 范围与保留条件

1. 用户要求将此前保留的代码一并提交推送；本批覆盖搜索态翻页、长按导航、快捷键冲突判定和置顶组合游标，不包含本地工具配置。
2. 长按先逐条移动，再按页加速；普通、搜索、多选状态的翻页守卫一致，仍保护别名弹窗和空列表。
3. 主层快捷键保留项与实际默认绑定一致；设置页输入保护保留。mainFocus 与更高优先级弹层不同时生效。
4. 置顶组合推进游标时不改成员列表或 currentType；其他 Tab 的组合、空组和循环回绕保持原有语义。
5. 过滤函数作为可复用导出保留；Main 与 quickPasteRuntime 尚未接入同一入口，不能宣称已消除两处匹配逻辑。未改变其原有调用链。
