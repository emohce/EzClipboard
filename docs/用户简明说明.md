# 超级剪贴板 · 简明说明

> 面向使用者，与开发文档 [插件核心要素说明.md](插件核心要素说明.md) 对应。

【核心功能】

- 记录：倒序自动记录(使用即刷)
- 预览：文本/图片, 预览滚动
- 收藏：持久化, 标签, 备注
- 加锁: 短期防删
- 别名: 增强区分, 以别名粘贴
- 置顶: 单项置顶, 多选组合置顶
- 搜索：过滤(文字|描述|备注|别名), 有锁|全部
- 性能：SQLite 底层存储 + 分页加载（触底追加），大数据量下保持流畅

---

【键盘操作】

> 配置和存储层使用 compact shortcutId，规则见 [`../vibe/specs/260613-SettingUiModify/260614-shortcut-compact-semantics.md`](../vibe/specs/260613-SettingUiModify/260614-shortcut-compact-semantics.md)。

* `↑` `↓` / `Tab` 上下移动，`←` `→` 切换 Tab 页
* `space` 多选，`cr` 粘贴，`del` 删除, `c-cr` 粘贴并加锁, `c-del` 加锁也删
* `c-s` 收藏/取消，`c-u` 锁定/解锁, `c-s-u` 搜索-有锁|全部
* `c-right` 打开抽屉，`c-left` 查看全文 (相反方向键|`esc` 取消)
* `a-1~9` 快速复制第 1~9 项，`c-a-1~9` 执行抽屉第 1~9 项
* `f2` 编辑别名(收藏tab区分), 单文件 `s-cr` 以别名粘贴
* `a-p` 置顶/取消置顶当前项
* `a-g` 多选后打开组合编辑（拖拽排序，`a-u/e` 批量移动，`cr` 保存，`esc` 取消）, 已有组合则清空
* `a-u/e` 单页上/下滚动，`c-s-left/right` 跳缓存首尾
